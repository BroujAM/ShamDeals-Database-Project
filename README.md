# ShamDeals Database Project

مشروع قواعد بيانات مخصص لتطبيق التجارة الإلكترونية (ShamDeals).

## محتويات المشروع
* **project.sql**: ملف الاستعلامات وقواعد البيانات.
* **ShamDeals Database.docx / .pdf**: التوثيق الشامل والمفصل للمشروع.
* **Untitled Diagram.drawio**: مخطط العلاقات بين Entities والمخطط المفاهيمي (ERD).

## الأداة المستخدمة
* MySQL Workbench
* Draw.io لتصميم المخططات
